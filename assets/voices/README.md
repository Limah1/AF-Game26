# Dublagem

Sistema compartilhado por diálogos do Hospital e pelo minigame DoiAqui.

Os áudios do Hospital ficam organizados em
`assets/hospital/<profissional>/audio/`. O JSON correspondente fica na pasta
do profissional. Consulte `assets/hospital/README.md`.

## DoiAqui

Arquivos esperados pelo `Main.gd`:

- `res://assets/voices/doiaqui/intro.ogg`
- `res://assets/voices/doiaqui/pain_headache.ogg`
- `res://assets/voices/doiaqui/pain_armPain.ogg`
- `res://assets/voices/doiaqui/pain_fever.ogg`
- `res://assets/voices/doiaqui/pain_wound.ogg`
- `res://assets/voices/doiaqui/correct.ogg`
- `res://assets/voices/doiaqui/incorrect.ogg`

`.wav`, `.mp3` ou `.ogg` podem ser usados; ajuste o caminho no código se a
extensão for diferente.
