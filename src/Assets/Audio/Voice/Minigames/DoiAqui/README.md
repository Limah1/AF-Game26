# Dublagem

Sistema compartilhado por diálogos do Hospital e pelo minigame DoiAqui.

Os áudios do Hospital ficam em
`src/Assets/Audio/Voice/Hospital/<Professional>/`. O JSON correspondente
continua na pasta do profissional. Consulte `assets/hospital/README.md`.
